# ADR 006：本地控制台

> 状态：已采纳（2026-08-28）
> 相关：[ADR 002 声纹准入](002-speaker-verification.md) · [ADR 005 派发与工具门](005-task-dispatch-model.md)

## 背景

平台层齐了，产品跑不起来。装一次 Vox 要记十几条命令：录声纹、配四个模型路径、改四个
TOML、构建球、启动运行时。而**没有任何一个地方能回答「我还差哪一步」** ——
`plugin.diagnose()` 有答案，但它只在 Python 里，用户看不见。

同时唯一的入口 `scripts/run_desktop.py` 只从 stdin 读文本，语音全链路只存在于
`scripts/acceptance/live_conversation.py`（一个头部就写着「需要人在场」的验收脚本，
而且把模型路径和 `speaker="owner"` 都硬编码了）。

## 决策

新增一个**本机回环的 web 控制台**：`core/console/` + `scripts/run_console.py`。
它是一份**可操作清单**，不是仪表盘：每一行要么是一个能做的动作，要么是一个还没就绪
的东西。

### 1. 标准库 `http.server`，零新依赖

参照对象是 VoxCord（本项目前身）的 FastAPI + React/Tailwind 那一套。不采用，理由与
本项目已经给过两次的理由相同：`tomllib` 没换成 PyYAML、JSON Schema 校验器手写没引
`jsonschema`。这里的路由面只有二十几个端点，不值得 starlette + pydantic + uvicorn +
anyio 四个包和一条 node 构建链。

副作用是有价值的：控制台因此**与 `desktop/` 完全隔离**，唤醒球和控制台可以同时开发
而不共用一个文件。

### 2. 强制回环 + 每请求 token

这个模块开了一个监听端口，安全面确实扩大了，所以三条不可协商：

- **绑定地址是被检查的，不是默认的。** `0.0.0.0` 直接拒绝构造，不是打个警告继续。
- **每个请求都要 token，包括页面本身。** 前端是一个内联了 CSS 和 JS 的单文件 HTML，
  所以不存在「第二个请求需要豁免」这件事。没有未认证的面可以拿来试探端点名。
- **`--no-token` 存在，而且大声说出来。** 预览工具打开 URL 时不会带查询串，所以需要
  一个开发模式；它只在回环上允许、启动时打印警告、`/api/state` 里如实上报。

token 从不进日志（`log_message` 被静默覆盖，默认实现会把带 token 的 URL 写到
stderr），从不进 `describe()`，从不出现在响应里。

### 3. 安全边界不可从网页改

这是本 ADR 最重要的一条。控制台能改配置，但**能改的键是白名单**：

| 不可从网页改 | 为什么 |
|---|---|
| `shell.enabled` `shell.allow` | 「说一句话就能执行命令」的第一、二层 |
| `fs.roots` `fs.denied_names` `fs.denied_dirs` | 沙箱边界 |
| `speaker.require_verification` | 声纹门总开关 |
| `agents[N].command` `args` `cwd` | 决定**跑哪个可执行文件** —— 从网页改它等于远程代码执行 |
| `agents[N].url` | 决定**数据发到哪** |
| `agents[N].env_passthrough` | 决定**子进程继承哪些凭据** |
| `agents[N].name` `kind` | 前者是路由成功率的统计键，后者选适配器类 |
| `mcp.require_confirmation` | 远端工具执行前的最后一道闸 |
| `servers[N].allow` `auto_allow` | 改了只会**放宽**：空 allow = 全部允许，auto_allow 就是免确认名单 |
| `servers[N].command` `args` | 同 agent |

留下的是参数、阈值、线程数、开关。**关掉一道防线应该是一次打开编辑器的动作**，那是
一个需要意图的动作；点一个 toggle 不是。

这些键**仍然显示**，只是不可编辑。藏起来更糟：一个人想弄清「为什么这个 agent 在跑
那条命令」需要看见那条命令，而「为什么这里改不了」的答案应该写在页面上而不是
docstring 里。

### 4. 控制台不确认 `shell.run`

确认面**恰好一个**，那是唤醒球（FR-6.13）。第二个确认面意味着同一条命令可以从一个
用户没在看的窗口被批准。控制台只报「有一个待确认，请在球上确认」，连命令原文都不显示。

### 5. 配置编辑是行级替换，不是序列化

`tomllib` 只读，标准库没有 TOML 写入器。把解析后的 dict 序列化回去会删掉文件里所有
注释 —— 而在这个项目里注释是承载理由的那一半（`speaker.toml` 解释了为什么阈值是 0.5、
以及它必须按 REAL-MIC 实测调定）。一个静默删掉这些的设置界面是伪装成功能的降级。

所以 `core/config_edit.py` 编辑**行**：只能改已存在的键（加键是代码改动，因为每个
loader 都把未知键当错误）、只支持单行标量与内联数组（多行数组按名字拒绝）、写入前用
该配置自己的 loader 校验候选文件，通不过就不落盘。

### 6. 浏览器录音，音频只在内存

声纹注册从命令行搬进浏览器：`AudioContext` 取 Float32 → 前端自己降采样到 16 kHz →
前端自己写 WAV 头 → base64 上传。后端只需标准库 `wave`，不需要编解码器。

红线 1 全程成立：解出来的数组直接交给 `SpeakerVerificationProvider.enroll`（只留
embedding），字节从不落盘、从不进日志、从不进事件或错误消息。前端也报每段的时长与
RMS，好让一段偏轻的录音当场重录而不是在校验时才发现。

### 7. 记忆只显示中期事实，不显示对话轮次

事实本来就在 `memory/facts/*.md` 里人类可读，显示它们不增加暴露。轮次是所有说过的话
的转写，而控制台没有任何一个需要显示它才能回答的问题。

档案编辑器编辑的是**文件**，不是数据库行 —— 文件是事实来源，SQLite 是它上面的索引
（ADR 004）。改数据库会让两者失步，而且失步的方向是丢掉手写的那一份。

### 8. 第二版界面：九个视图，一次只看一个（2026-08-28）

第一版是一页十一块，从上到下滚。使用者的判断是「可配置的选项太繁琐了」，并点名要保留
六个模块：**模型配置**（ASR/TTS/LLM，带服务商预设与自定义）·**声纹**·**本机 agent
连接与测试**·**本人档案**·**技能与 MCP**·**唤醒球选项**。

第二版（`core/console/static/index.html`，2668 行、仍然是单文件内联）改成侧栏 +
九个视图：那六个模块，加一个**运行态**总览、一个只读的**安全边界**、一个**调试**。
砍掉的面板：事件流、记忆检索、麦克风启停、五个单项模型测试。相应的后端动作
（`events` / `memory` / `mic_start` / `mic_stop` / `test_*`）**保留**，因为
`scripts/run_console.py --voice` 仍然调 `mic_start`，而删掉一个还有调用方的动作
是两件事一起做。代价要说清：**页面上现在没有开麦克风的入口**，要开麦克风得用
`--voice` 启动。声纹注册不受影响 —— 它走浏览器的 `getUserMedia`，与采集线程无关。

新增的一项是**读数的第三种编码**：刊头一块 WebGL2 极光，能量与色相由 `state` 驱动
（空闲慢而暖、在听/在想快而亮、等确认转琥珀、出错或连不上转红并压低起伏）。拿不到
WebGL2 就退到静态渐变；系统要求减少动效、标签页在后台、或当前不在总览页时它不跑。
它不是装饰：同一份读数另外两种编码是等宽读数行和状态色带。

### 9. 模型配置：预设表在代码里，端点未经复验

`config/models.toml` 一套 ASR+TTS+LLM 叫一个 profile，多套并存，`active` 指生效的那套。
`core/console/providers.py` 是服务商预设表（11 条 LLM + 4 条 ASR + 4 条 TTS），
`core/models_config.py` 是它的 loader 与写入器。四个端点：`GET /api/models`、
`PUT /api/models`、`POST /api/models/probe`、`POST /api/models/fetch`。

后两个的分工是「要不要发密钥」，不是重复：`probe` 不带凭据只取状态码，所以 `401` 是它
的好结果；`fetch` 带凭据并读 body，把模型名解析出来填进「模型名」那个 `<datalist>`，
所以 `401` 在它这里是失败、错误消息里点名该设哪个环境变量。解析认三种形状
（`data[].id`、`models[].name`、顶层数组），去重排序后上限 300 条；body 上限 1 MiB，
超了报错而不是截断（半个 JSON 解不出东西，说清楚比猜好）。用 `<datalist>` 而不是把
输入框换成 `<select>`：拉到的列表是「这个端点列出来的」不是「全部的」，收掉手打的自由
会让一个真实存在但没被列出的模型变成填不进去。

三条约束：

- **文件里永不写密钥，只写环境变量名。** `key_env` 必须形如 `VOX_LLM_KEY`；任何形似
  凭据的值（`sk-`/`ghp_`/`AKIA`… 前缀，或一个 24 字符以上、大小写数字混合且没有分隔符
  的串）**整条拒绝而不是打码** —— 打码会把密钥留在文件历史里。
- **预设值不落盘。** 页面为了显示会把预设的 `base`/`proto`/`key_env` 填进输入框，写回时
  这些字段被丢掉（除非文件里本来就有那个键，或服务商是 `custom`）。否则文件里会多一份
  端点副本，而将来改预设表改不到它。**实测过的回归**：第一版做完之后，打开页面点一次
  「保存方案」会凭空长出四行，全是 `providers.py` 里已有的值。
- **探测是本页唯一的出网动作，而且由守护进程发出。** 一次 `GET {base}/models`，**不带
  任何凭据**（所以 `401`/`403` 才是好结果：主机在、路径对、只是没给 key），不跟随重定向
  （跟了就是在报告另一台主机的健康），6 秒超时，**只取状态码，不读 body**。明文 HTTP
  只许回环、URL 带凭据拒绝 —— 与桥接、HTTP agent、检索后端同一条规则的第四份实现，
  理由与第三份写下的相同（见 `docs/backlog.md`）。

预设里的端点**抄自各家公开文档，本项目没有复验过**。判据是那颗「探一下」按钮，
`providers.py` 的模块注释和页面上都写着这句话，改的时候不要删。

`models.toml` **不在 `EDITABLE` 里**，这是刻意的：它由自己的端点写，带自己的白名单
（五个字段名）。放进 `EDITABLE` 等于给同一个文件开第二道门，而那道门的校验更弱。
它也是唯一一个**允许加键**的配置 —— 因为它的表就是数据（一个 profile 一张表），
`core/config_edit.py` 的 `set_section` 只服务这一类文件，且必须点名表名才够得到。

## 后果

- **发现并修掉一个既有缺陷**：控制台是多线程的（`ThreadingHTTPServer` 工作线程 +
  turn pump 线程 + 音频回调线程），而 `SqliteMemoryStore` 的连接是懒建的、绑在第一个
  查询的线程上。第二个线程访问时 `sqlite3` 抛 `ProgrammingError` —— 而且是在第一次
  查询已经成功之后，读起来像调用方的 bug 而不是设计问题。已修：`check_same_thread=False`
  加一把 `RLock` 串行化。7 条真线程测试钉死（`tests/test_memory_threads.py`）。
- **又发现并修掉一个既有缺陷（2026-08-28）**：`config_edit` 用 `read_text` 读、
  `write_text` 写，而前者把 `\r\n` 归一成 `\n`、后者在 Windows 上又翻译回去 —— 所以
  控制台保存**任何**配置都会把整个文件的行尾重写一遍。**在 git 里看不见** —— 本仓库
  `core.autocrlf=true`，提交时会归一化掉，所以代价不是 diff 噪音：它让一次「什么都没改的
  保存」也把文件的 SHA-256 换掉，而「零字节差异」正是配置写入唯一可自动化的取证判据
  （`docs/routines.md` 的写入取证一节）。一个自称「只改一行」的写入器不该重写整份文件。
  已修：行尾从字节里探出来、写入用 `newline=""`。LF 与 CRLF 各两条测试。
- 攻击面确实扩大了一个监听端口。缓解就是上面第 2、3、4 条。
- 证据等级：接线与 API 是 **AUTO**（`tests/test_console.py` 103 例 +
  `tests/test_models_config.py` 60 例），渲染页面是 **SIM**（快照 + Edge headless 截图，
  实测九个视图全部吃到真实读数、零 console 错误），对着它说话是 **REAL-MIC**。
  端点探测打到本机 Ollama 时是真的发了请求（拿到 `WinError 10061 拒绝连接`），
  打云端服务商**没试过**。

## 被否决的方案

- **把设置做进唤醒球**：球是 148px 的透明挂件，它承载的是六态和确认卡。一个配置表单
  在那里是错的表面。
- **FastAPI + React**：见第 1 条。
- **只做只读诊断页**：那不降低使用门槛，只是把 `diagnose()` 换了个显示位置。
- **允许网页改 `command`**：这是最诱人的一条（「让用户自己配 agent」），也是最危险的
  一条。见第 3 条。
