## 1. 产品定位与范围

### 1.1 一句话定义

面向 Windows 的 EvoX 本地语音唤醒对话客户端:免手动、免热键,说出唤醒词即可与 EvoX 进行连续语音对话。

### 1.2 目标用户与场景

| 场景 | 描述 |
|---|---|
| 双手占用 | 用户在写代码/看文档时不切窗口,直接语音提问 |
| 常驻待命 | 唤醒球悬浮桌面底部,不占任务栏、不抢焦点 |
| 连续追问 | 一次唤醒后可多轮对话,无需重复唤醒词 |
| 随时打断 | 回复过程中说话或点击即可中断,立即进入下一轮 |

### 1.3 明确不做(out of scope,范围外)

- 不做云端语音识别/合成(违反本地优先红线)
- 不做多语言唤醒(v1 仅中文 `你好问问`)
- 不做语音账号识别/声纹
- 不做移动端与 macOS/Linux(v1 仅 Windows x64)
- 不做会话历史管理界面(由 EvoX 主体负责)
- 不保存任何音频文件

### 4.2 发布必过清单(Definition of Done)

一个需求只有满足以下全部条件才算完成:

1. 功能在**真实 Windows 主机**上可用(不是 mock、不是 headless)
2. 有自动化测试覆盖核心路径
3. 失败路径有明确诊断输出,不静默失败
4. 资源(设备、原生句柄)确认释放
5. 验证等级与实测数据记入 `prototype-results.md`
6. 相关例程写入 `routines.md`

### 4.3 七项发布阻塞项(与 ADR 一致)

| # | 阻塞项 | 关闭条件 |
|---|---|---|
| 1 | 中文唤醒质量验收 | 安静/远场/噪声/重复四场景 REAL-MIC 统计,误触率与漏触率达标 |
| 2 | 真机 Silero 端点验收 | REAL-MIC 语音起止判定正确 |
| 3 | 真实 EvoX 桥接 | REAL-EVOX:发送/增量/取消/超时/重连全通 |
| 4 | 流式首字延迟 | REAL-EVOX 实测 < 1.5s |
| 5 | 透明置顶窗口 | REAL-WIN:透明合成、DPI 125–175%、多显示器、托盘、RDP 降级 |
| 6 | 持续运行画像 | ≥30 min,CPU/内存/FPS 四状态无漂移 |
| 7 | 提供器可替换性 | 契约强制,无 SDK 类型泄漏(保持) |
