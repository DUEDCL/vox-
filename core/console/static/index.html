运行态

四个读数、一条就绪板、一条本会话的状态色带。数据源只有 /api/state 一个。

读数

就绪 是 readiness 里 ready=true 的条数比总条数； 轮次 与 运行 直接来自 turns / uptime_s； 工具 是运行时 describe() 报的工具数加 agent 数。读不到就显示 —，不猜。

就绪板

每一格点开看 detail 与 hint 原文。颜色不是唯一载体 —— 判词（就绪 / 缺 / 坏）同时写成文字。

状态色带

这条带子只记本会话自己的轮询（每 2.3 秒一格，最多 96 格）。 后端没有历史状态端点，页面一刷新它就从零开始 —— 它不是服务器侧的时间线。

模型配置

一套 ASR + TTS + LLM 叫一个方案，多套并存，active 指向生效的那套。

方案

落盘

预设端点抄自各家公开文档与参考项目，本项目没有复验过。判据是「探一下」那颗按钮： 它只打一次 GET {base}/models，401/403 是好结果 （主机在、路径对、只是密钥不对），404 说明路径拼错，超时说明这条路不通。 这是本页唯一会出网的动作，而且由守护进程发出、不是从浏览器发出。

配置文件里永不写密钥，只写环境变量名（key_env），值从环境变量读。

合成音色（云端 TTS）

本机合成（sherpa）读 models/ 下的 VITS 模型，没有音色可选。 换成 dashscope 之后音色才有意义 —— 下面这两栏写进 config/voice.toml 的 [tts]，改完要重启。

音色表不是实时拉的。百炼没有列举系统预置音色的接口（有列表接口的是「声音复刻」， 只列你自己复刻出来的）。所以上面那两栏是可输入的建议而不是封闭下拉：表里没有的 音色照样能填，由「试一句」去判 —— 它真发一次合成请求，通不通看得见。

其余语音参数（config/voice.toml）

这一栏渲染的是 voice.toml 里没有专用控件的那些可改键 —— 应答音那几句话、连续对话开关、解码束宽、自适应增益都在这里。 它按 /api/config 返回的内容自己长出来，所以以后加了新键**不会漏在页面外**。 专用控件另有其页：合成在「模型配置」，输入设备在「运行态」，球在「唤醒球」。

原始读数

模型缺失、无人注册、校验抛异常，一律落在拒绝一侧 —— 这道门是 fail-closed 的， 拒绝也是它在工作。质量门（时长 / rms / 削波）挡的是不可用的录音， 它不是反录音回放（ADR 002 的已知局限）。

本机 Agent

四种接法：cli evox acp http。可用性由 check() 报告。

清单与试跑

命令不在 PATH 的条目保留而不是隐藏：丢掉它会让「少一个 agent」和「配错一个 agent」 变成同一种表现。evox 是一次阻塞 POST，不流式，界面不给它套增量外壳。

条目设置

command / args / url / env_passthrough / name / kind 显示但不可从网页改：前三个决定「跑哪个可执行文件、数据发到哪」， 从一个网页改它们等于远程代码执行。agents.toml 在 schema 层面就没有放密钥的键， 要给 agent 传 key 只能在 env_passthrough 里写变量名。

本人档案

memory/facts/*.md 就是事实本身，SQLite 只是它的索引（ADR 004）。

文件

「常用字段草案」（姓名 / 称呼 / 时区 / 语言偏好 / 常用路径）是我拟的，字段清单还没跟你确认， 所以它只是往编辑器里插一段 Markdown，不是一个固定表单 —— 文件仍然是事实本身。

写在这里的事实会被召回并拼进 agent 请求。凭据形状的文本整条拒绝而不是打码 （多行私钥正是打码会留下正文的例子）。记忆事件永不带文本，只带 id / 计数 / 标签。

技能与 MCP

技能 = 平台自有工具 + MCP 远端工具。两者走同一道政策门（ADR 005），所以放在一页。

已注册的技能

仓库里没有独立的 skill 注册表（config/ 下只有 voice / tools / speaker / models / memory / mcp / agents 七个文件），所以这一列直接来自运行时 describe() 报的工具名。

MCP

没有单独的「测连接」端点，所以连接证据用的是运行时报的 alive 加工具数 —— 要一颗真正的探测按钮得在 routes.py 里加 mcp_probe。

require_confirmation / allow / auto_allow / command 不可从网页改：第一个是远端工具执行前的最后一道闸， 中间两个改了只会放宽（空 allow 等于放开该 server 的全部工具），最后一个决定跑什么。 写坏的 MCP 配置不许落盘，服务端先校验再写。
